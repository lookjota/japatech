# JAPA TECH Design System

Direção v1: **Technical Precision** e **Precision Without Clutter**.

- Iconografia: ícones lineares, geométricos, simples e com stroke consistente; usar uma biblioteca leve compatível com essa regra quando os ícones de produto forem definidos. Emojis, glow e ícones decorativos não fazem parte do sistema.
- Motion: transições curtas de feedback (150–250ms), sem parallax ou animações contínuas. `prefers-reduced-motion` reduz as transições automaticamente.
- Superfícies: contraste entre `--color-background`, `--color-surface`, `--color-brand` e `--color-surface-dark` prioriza bordas e hierarquia antes de sombras.
